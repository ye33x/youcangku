# 架构与模块对照

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | Spring Boot 3.2.5 / JDK 17 | `jakarta.*` 命名空间 |
| ORM | MyBatis-Plus 3.5.7 | 单表 CRUD 走 BaseMapper，复杂查询用注解 SQL |
| 数据库 | MySQL 8.0 | utf8mb4，`utf8mb4_0900_ai_ci` |
| 鉴权 | JWT（jjwt 0.12.5） | 无状态，三端共用一套签发逻辑 |
| 密码 | PBKDF2-HMAC-SHA256 | JDK 原生，参数写进哈希串，可平滑升级 |
| 前端 | Vue 3 + Vite + Element Plus | 三端页面通过路由前缀区分 |

## 三端隔离方式

不靠为每个接口加注解，而是用**路径前缀 + token 角色**两步校验（`AuthInterceptor`）：

| 前缀 | 需要的角色 | 说明 |
|---|---|---|
| `/api/public/**` | 无 | 登录、注册、公告 |
| `/api/user/**` | USER | 用户端 |
| `/api/merchant/**` | MERCHANT | 商家端 |
| `/api/admin/**` | ADMIN | 管理端 |

这样新增接口时天然不会漏加权限，减少「忘记加注解导致越权」的低级问题。

| GET | `/api/user/products/{id}` | 商品详情 |
| POST/GET/PUT/DELETE | `/api/user/cart/**` | 购物车增删改查、结算预览 |
| GET/POST/PUT/DELETE | `/api/merchant/products/**` | 商家商品管理、上下架 |
| GET/PUT | `/api/admin/reviews/**` | 评价与回复审核 |
| GET | `/api/admin/logs` | 操作日志查询（无删除接口） |
